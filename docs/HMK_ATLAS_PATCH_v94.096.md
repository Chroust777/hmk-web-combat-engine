# HMK Keeper’s Ledger v94.096 – Historie mapových objektů

Navazuje na v94.095. V sekci Trasy, oblasti a kreslení je sbalený seznam uložených objektů aktuální mapy s počtem položek. Obsahuje trasy, oblasti, kružnice dosahu, kresby, šipky a texty včetně starších objektů bez názvu. Tlačítko názvu vycentruje objekt, upraví přiblížení a zvýrazní jej. Skrytá vrstva se při výběru nemění v uložených datech: pouze vybraný objekt se dočasně zobrazí, Esc náhled ukončí. Tlačítko Smazat po potvrzení odstraní celý objekt včetně jeho bodů přes stávající chráněný zápis; Zpět/Znovu fungují. Při odmítnutém zápisu je objekt obnoven. Při přechodu od rozpracované kartografie se potvrzuje zahození neuložených změn; rozpracovaná historie družiny se dokončí stávajícím postupem nebo se přechod zablokuje při neúspěšném uložení. Beze změny datového formátu a ostatních herních modulů.

Testy: Chromium, produkční CSS, skutečné kliky a tažení v izolovaných modulech Atlasu s paměťovým adaptérem: všech šest typů na obou mapách v obou rolích, vycentrování bez zápisu, dočasný náhled skryté vrstvy, smazání celé trasy, odmítnutí zápisu, undo/redo, opětovné načtení seznamu, regresní testy textu a mlhy. Bez JS výjimek. Node syntax check PASS. Vzdálený GitHub Cloud, PDF.js a kompletní start produkční aplikace nebyly ověřeny.
