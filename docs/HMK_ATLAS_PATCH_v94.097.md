# HMK Keeper’s Ledger v94.097 – Kružnice, text a názvy objektů

Navazuje na v94.096. Kružnice dosahu má jediný střed a samostatný úchyt poloměru. Kliky do volné mapy při editaci nepřidávají vrcholy. Dříve uložené nadbytečné body kružnic se nevykreslují a při uložení jejich popisu nebo změně geometrie se opraví. Po umístění textu je automaticky otevřena editace názvu a poznámky; další kliky nevytvářejí body. Uložit změny uloží popis. Při novém výběru nástroje Text na mapě se pole vyprázdní. Při odmítnutém zápisu popisu zůstane formulář otevřený. Historie používá označení Typ - Název nebo Typ N; N je pořadí mezi všemi objekty daného typu na aktuální mapě (včetně pojmenovaných). Dosavadní navigace, smazání celého objektu a undo/redo zůstávají. Datový formát beze změny.

Testy: reprodukce obou závad ve v94.096 a regresní průchody Chromium nad skutečnými moduly Atlasu, produkčními CSS a izolovaným paměťovým adaptérem. Obě mapy, obě role: kružnice, kliky, přesun středu, změna poloměru, starší nadbytečné body, otevření polí po umístění textu, odmítnutí zápisu, poznámka v popupu, reset nového textu, typové názvy, historie všech šesti typů, smazání/undo. Dále navigace družiny a obousměrná mlha, škálování, hranice sektoru, rollback a starší data. Bez JS výjimek. Node kontrola syntaxe PASS. Vzdálený Cloud, GitHub Pages a PDF.js nebyly ověřeny.
