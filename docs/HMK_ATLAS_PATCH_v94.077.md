# HMK Atlas – patch v94.077: Zakrytí mapy a sbalené úplné operace

Základ: v94.076. V rámci Atlasu byla sekce **Mlha války** přejmenována na **Zakrytí mapy**.

Tlačítka **Úplně zahalit** a **Odstranit mlhu** jsou v nové podsekci **Další možnosti zakrytí**, která je ve výchozím stavu sbalená; po zavření hlavní sekce se znovu sbalí. Ovládání štětce a Zapnout/Vypnout mlhu zůstává přímo přístupné.

Zachováno: heslo `anakin` potvrzované pouze tlačítkem Odemknout, Esc, poloměry štětce 5 km / 0,2 km, cloudová data, obě mapy a všechny ostatní moduly. Žádný nový datový formát.

Instalace: Překopírovat soubory z ZIP do kořene stejného GitHub Pages repozitáře, nahradit existující soubory a obnovit Ctrl+F5. Nepřepisovat PDF a obrázky map.
