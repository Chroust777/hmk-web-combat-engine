# HMK Keeper’s Ledger v94.101 — Chat in the existing book

- Chat replaces the current main content slot in the existing `.shell .layout`. No dialog, backdrop, second book or new art. It uses the existing study scene, `journalShell`, shared chapter/spread/page classes, standard sidebar and top line. Close/Escape restore the original main DOM and scroll position; a normal application render remounts the chat on its newly rendered main slot. Sidebar navigation closes the chat before navigating. GM login/logout can be used directly in the sidebar.
- New color palette: white, light red, pink, orange, yellow, spring green, mint, turquoise, sky blue, lavender, purple, silver. GM retains his fixed light brown. Legacy colors are accepted when reading existing chat data; the old sand is not offered for new identities. Editing a legacy profile may retain its old color or select a new one; existing messages retain the color snapshot.
- `gameDate` now includes the calendar’s current TR date (or campaign day if TR origin is not established) and HH:mm. It is copied on send, never writes the calendar, and is unchanged on message edit. The actual device timestamp is unchanged. No historical time is fabricated for previous messages.
- Same chat JSON path and schema, no Atlas, campaign JSON, cloud connection, chronicle generator or artwork changes. A render caused independently by the application retains its usual behavior; Chat itself does not call render.

Tests: `node tools/test_94101_chat.mjs`, `node tools/test_94100_chat.mjs`, JS syntax checks. Chromium test used actual bundled source modules, production CSS and isolated fixture/storage. Verified one main content slot/one book, sidebar, GM login/logout, close and normal application rerender/navigation, empty independent names, light-red option, dynamic textarea, actual fixture calendar time (12:00), real timestamp, chronicle and preserved form/campaign. Original frame assets were injected for a visual check, but HTTP navigation is blocked in this environment and the full texture/background did not render in the screenshot. Remote GitHub Pages/Cloud was not exercised (CAS transport simulated in existing regression test).
